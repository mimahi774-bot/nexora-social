# NEXORA MVP — free starter

This is a responsive web prototype that works in a mobile or desktop browser.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Try creating a post, liking posts, switching views, and sharing post text.

## Publish it free
You can publish the static prototype using a free static-hosting tier such as GitHub Pages or Cloudflare Pages. Create a repository, upload these files, and follow that host's current deployment instructions.

## Important limitations
- Posts are saved only in the current browser using localStorage.
- No real accounts, global feed, cross-device sync, live chat, calls, server-side moderation, or real payments.
- Demo earnings are not real money.
- This prototype is not ready for public production use.

## Suggested next build steps
1. Create a GitHub repository and publish the static frontend.
2. Add authentication and a database using a free-tier backend (review current limits and terms first).
3. Implement secure messaging, image/video uploads, reporting/blocking, moderation, privacy controls, backups, and account deletion.
4. Add a payment provider only after eligibility, fees, legal/tax requirements, and payout rules are confirmed.
5. Test performance, security, accessibility, and privacy before inviting public users.
